# 城市酒店服务点评系统 · 使用说明

## 📁 文件结构

```
hotel-review/
├── index.html          ← 客人端 - 前台竖屏展示（主界面）
├── admin.html          ← 管理后台 - 店总/前台登录使用
├── css/
│   └── style.css       ← 全局样式（棕色奢华主题）
├── js/
│   ├── db.js           ← 本地数据库（localStorage）+ PMS接口预留
│   └── seed-data.js    ← 测试数据生成脚本
└── assets/
    └── logo.jpg        ← 酒店 LOGO
```

## 🚀 启动方式

**方式一：直接双击**
- 双击 `index.html` 在浏览器中打开（客人端）
- 双击 `admin.html` 在浏览器中打开（管理端）

**方式二：推荐 - 通过本地服务器**
```bash
# 在 hotel-review 目录下运行
npx serve . -p 3000
# 然后访问 http://localhost:3000
```

## 📱 使用流程

### 客人端（index.html）
1. 竖屏放置在前台，全屏打开浏览器
2. 界面显示"服务点评"，每30秒自动语音提醒
3. 客人点击好评 → 感谢页 → 自动返回
4. 客人点击差评 → 选择原因 → 感谢页 → 自动返回
5. 右下角"⚙ 管理"按钮可进入后台

### 管理后台（admin.html）
- **数据看板**：今日实时统计 + 7日趋势图 + 差评原因排行
- **统计报表**：按天/周/月统计，自定义时间段查询，Excel导出（店总）
- **评价记录**：明细列表，支持筛选和删除，Excel导出（店总）
- **系统设置**：修改酒店名/LOGO/语音内容/感谢语（店总）
- **账号管理**：管理员账号、差评原因自定义（店总）

## 🔧 生成测试数据
在浏览器控制台（F12 → Console）中粘贴运行 `js/seed-data.js` 内容

## 📡 捷信达 PMS 接口预留
在 `js/db.js` 中已预留 `_syncToPMS()` 函数框架（注释状态）。
待 GSHIS 提供 API 文档后，在 `系统设置 → PMS接口` 中填写地址和 Token 即可开启推送。

## ⚙ 华为平板推荐设置
1. Chrome/Edge 浏览器 → 开启"添加到主屏幕"
2. 进入"全屏模式"（F11 或浏览器菜单）
3. 在电源管理中设置"屏幕常亮"
4. 关闭其他通知提醒
